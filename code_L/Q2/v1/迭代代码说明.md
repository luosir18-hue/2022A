## 计算过程预设

### 模型思想

Q2 参数优化: 在 Q1 二自由度垂荡动力学约束下，以阻尼耗散率的稳态时间平均为目标，搜索最优 PTO 阻尼参数。常量阻尼情形同时使用解析频域模型（复幅值闭式解）和时域模型交叉验证；幂律阻尼情形使用纯时域网格搜索 + 局部精细搜索。

### 计算过程设想

1. **参数加载**: 从附件3（ω=2.2143行）读取 m_a, b_h, F；从附件4读取 m_f, m_o, R_f, ρ, g, k。K_h = ρgπR_f² 公式计算。
2. **情形一 (常量阻尼, 1D)**:
   - 频域解析解: 黄金分割搜索 P_lin(c) = ½cω²|ẑ_o−ẑ_f|², tol=1e-6
   - 时域验证: 黄金分割搜索稳态平均功率, tol=5 N·s/m
   - 输出功率曲线 (40点, 解析+时域双列)
3. **情形二 (幂律阻尼, 2D)**:
   - 粗网格: 16×11 = 176点, c0按(i/15)^2.5非线性分布, 每点20暖+10评
   - 局部精细: 粗网最优±25%c0 / ±0.12p, 9×9=81点, 每点25暖+15评
   - 最终评估: 最优参数处30暖+30评精细评估
4. **稳态验证**: 两种情形最优点各输出40周期逐周期平均功率报告

### 规模与降算预设

- 时域积分步长 dt=0.001s, RK4单步
- 粗网格评估: 20暖+10评=30周期/点, 176点, ~15M RK4步
- 精细网格评估: 25暖+15评=40周期/点, 81点, ~9.2M RK4步
- 黄金分割搜索 (时域): ~22次评估, 每次25暖+15评, ~6.2M步
- 总规模: ~35M RK4步, C++ -O2下约15-30秒

### 结果评价与分析

- 常量阻尼: 解析P*=229.33W (c*=37193.8), 时域P=232.36W (c*=37400.4), 差值<1.5%
- 幂律阻尼: c0*=100000 (边界最优), p*=0.4, P*=230.25W
- 稳态验证: 两情形均在第10-20周期内达到稳态判据 (|ΔP|/P < 1e-4)
