## 结果解释

### 2.1 情形一：解析—时域交叉验证

常量阻尼为线性系统，频域复幅值解给出闭式平均功率
P̄_lin(c) = ½ c ω² |ẑ_o(c) − ẑ_f(c)|²，可作为时域结果的独立校验。
两条路径得到的最优 c* 一致（解析 37193.8 / 时域 37400.4），但功率相差约 3 W（1.3%）：
解析法直接取稳态单频闭式值，时域法对 30 个周期做数值平均，二者因稳态窗口与离散化存在微小偏差。该量级差异在竞赛容差内，但建议在论文中统一口径（推荐报解析值 229.33 W，并说明时域校验一致）。

### 2.2 情形二：二维搜索与边界最优

幂律阻尼无闭式解，采用粗网格（16×11，c₀ 非线性分布）+ 局部精细（9×9）搜索。
最优落在上界 c₀*=100000、p*=0.4，属边界最优：说明在题面允许范围内进一步增大 c₀ 仍可能提升功率，目标函数在顶部平坦。该结论与"c₀ 越大阻尼越强、相对速度越小但系数越大"的权衡物理一致。

### 2.3 与上一问关系

Q2 完全复用 Q1 的垂荡动力学骨架（符号 z_f,z_o,ξ 一致），仅将决策变量由固定阻尼改为待优化阻尼参数，目标由"求响应"改为"最大化 PTO 平均输出功率"。本问数值结果不回填 Q3/Q4。
