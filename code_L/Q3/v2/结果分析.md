## 二、结果解释与相邻小问对比

### 2.1 物理意义

模型 `M·ÿ + C·ẏ + K·y = f(t)` 是四自由度常系数线性受迫振动系统：

- **垂荡通道**：由外激励 `F·sin(ωt)`（F=3640 N, ω=1.7152 rad/s）驱动，`K_h`、`C_h` 提供静水恢复与阻尼，
  响应 `z_f, z_o` 表现为受迫稳态振荡，幅值由激励频率与系统固有频率之比决定。
- **纵摇通道**：由力矩型激励驱动，`K_p` 含 `k_θ − m_o g ℓ_e` 与 `K_θ + k_θ − m_o g d`，
  **显式保留振子重力摆锤项**（详见 `模型/Q3/v3` 数学模型 `K_p` 定义），因此纵摇表现为自重耦合下的受迫振荡。
- **振子—浮子耦合**：在小运动假设下，相对位移 `u` 与相对角 `φ` 维持微小量，
  与 `模型/Q3/v3` 的"近似刚接+小相对运动"建模前提自洽。

### 2.2 与上一代码版本（Q3/v1 非线性拉格朗日）对比

- **模型关系**：本版是 `模型/Q3/v2` 非线性系统在原点附近的小角度线性化（L1），二者物理一致、参数一致。
- **垂荡一致性**：线性化后垂荡方程不含角度耦合，与 v1 在垂荡上高度吻合（量级与相位一致）。
- **纵摇一致性**：纵摇响应幅度受"是否计入振子重力矩项"影响显著；
  本版显式保留 `−m_o g ℓ_e`，纵摇幅值高于任何忽略该项的简化版本，符合线性化前 v2 模型的自重耦合特征。
- **数值可靠性**：两版本（无注释 `solve.cpp` 与注释 `solve_注释.cpp`）输出逐字节一致；
  六矩阵块特征值与 `模型/Q3/v3` 文档给定值逐位吻合，验证控制方程编码正确。

### 2.3 结果边界与可信区间

- 响应全程有界，无数值发散，符合线性受迫系统稳态行为。
- 小角度/小相对运动判定 PASS，但 `u/ℓ_e` 已逼近 0.20 阈值，说明线性化在该参数下处于适用边界，
  若后续调整激励幅值或参数应重新校验 `result3_线性化适用性.csv`。
