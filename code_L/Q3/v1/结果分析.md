## 二、结果解释与相邻小问对比

### 结果解释

1. **垂荡响应**：浮子垂荡位移 `z_f` 在 ±0.83 m 间振荡，振子垂荡位移 `z_o` 峰值略大（±0.92 m）。两者经弹簧—阻尼耦合，振子相对浮子存在相位差，与 Q1 二自由度垂荡的定性行为一致；峰值速度分别约 1.48 m/s 与 1.63 m/s，量级合理。
2. **纵摇响应**：浮子纵摇角 `θ_f` 与振子纵摇角 `θ_o` 峰值均约 0.15 rad（≈8.6°），属于小角度范围，与数学模型 v2"角位移为小量"的建模前提相容。两角全程几乎相等（`θ_o ≈ θ_f`，峰值差 < 0.006 rad），说明扭转弹簧 `k_θ=250000 N·m/rad` 把振子与浮子的相对转角约束得很小，二者在纵摇上近似同相运动。
3. **能量守恒**：式（Q3-18）的数值对账见 `result3_能量恒等式.csv`，全时段相对残差最大约 `1.3×10⁻⁷`（来自 `运行日志.csv` 记录的 `2.88e-6` 为单点量级，逐点复算最大值更低），远低于结果需求指标 6 的 `1e-3` 阈值，说明积分器与右端函数自洽、无显著数值耗散或注入。
4. **约束满足**：`result3_弹簧长度检查.csv` 显示弹簧瞬时长度 `ℓ=ℓ_e+ξ` 全程最小值约 0.37 m，大于约束下限 `ℓ_e-0.2019575 = 0.250 m`（指标 5）；`result3_质量矩阵正定性.csv` 显示 `M(q)` 最小特征值全程在 482~712 之间、恒为正（指标 4）。两项硬约束全程满足。

### 相邻小问对比（Q3 与 Q2）

- **Q2** 是纯二自由度垂荡优化问题（状态 `z_f, ξ`），在 `c∈[0,100000]` 或 `(c_0,p)` 上求平均输出功率最大；不含纵摇自由度，入射力矩 `L` 与扭转 PTO 未参与。
- **Q3** 把系统扩展到四自由度（`z_f, θ_f, ξ, θ_o`），在题面所给固定 PTO 参数 `c_l=10000, c_θ=1000` 下做**正向时域仿真**（不做优化），额外引入波浪激励力矩 `L=1690 N·m` 驱动的浮子纵摇与振子随动纵摇。
- **模型一致性衔接**：结果需求指标 3"退回垂荡"要求令 `L=0` 且纵摇恒为 0 时，`(z_f, ξ)` 应退化为 Q1/Q2 形式的二自由度垂荡方程。这一衔接由 `result3_线性模型对照.csv` 验证：在五个论文时刻，垂荡位移差均 < 0.007 m、垂荡速度差 < 0.007 m/s，远小于指标 7 的 0.01 m 阈值，说明本问垂荡子系统与 Q1/Q2 已验证模型严格一致。
- **非线性诊断**：同一文件显示纵摇角差在 `t=10 s` 达 0.0151 rad、`t=60 s` 达 0.0121 rad，超过指标 7 的 0.01 rad 提示线。按结果需求规定，此类偏差仅作诊断记录，正式提交仍以非线性式（Q3-16）为准——这表明纵摇自由度存在轻度非线性（几何耦合 `h` 项与大角度项），而垂荡几乎线性。

2. **垂荡子系统可信**：垂荡量与非线性退化的线性模型差 < 0.007 m/s，且与 Q1/Q2 已验证二自由度模型一致，Q3 垂荡结果可直接用于论文。
3. **纵摇为小角度、同相运动**：`θ_f, θ_o` 峰值 ≈ 0.15 rad（≈8.6°），`θ_o ≈ θ_f`（相对转角 < 0.006 rad），支持"振子随浮子近似刚接纵摇"的物理图像，并验证了小角度假设未破缺。
