## 问题目标

问题二仍只考虑浮子与振子的垂荡运动。需要在题目给定的参数范围内，分别确定常量阻尼系数和速度相关阻尼参数，使 PTO 阻尼器在稳定运动阶段的平均机械输出功率最大。

常量阻尼情形是线性系统：稳定后位移是与波浪同频率的余弦加正弦。把这组表达式代入运动方程，比较 \(\cos(\omega t)\) 和 \(\sin(\omega t)\) 的系数，得到关于待定系数的代数方程，从而写出平均功率对 \(c\) 的显式函数，再求导求最大值。速度相关阻尼情形是非线性系统：稳定相对速度一般不再是单一正弦，需要先数值求解运动方程，再由时间积分计算平均功率，最后在参数范围内寻找最大值。

## 符号与参数

Q2 沿用 Q1 的浮子质量、振子质量、弹簧刚度和静水恢复刚度。本问使用的主要符号如下。字母在后文公式下仍会再次说明。

| 符号 | 含义 | Q2 取值/来源 |
|---|---|---|
| \(m_f\) | 浮子质量 | 4866，附件 4 |
| \(m_o\) | 振子质量 | 2433，附件 4 |
| \(m_a\) | 浮子垂荡附加质量 | 1165.992，附件 3 |
| \(b_h\) | 浮子垂荡兴波阻尼系数 | 167.8395，附件 3 |
| \(F\) | 波浪激励力振幅 | 4890，附件 3 |
| \(\omega\) | 入射波圆频率 | 2.2143，附件 3 |
| \(k\) | 直线弹簧刚度 | 80000，附件 4 |
| \(K_h\) | 垂荡静水恢复刚度 | 31557.2982，由 Q1 计算 |
| \(c\) | 常量阻尼系数，第一种情形的决策变量 | \([0,c_{\max}]\) |
| \(c_0\) | 速度相关阻尼的比例系数 | \([0,c_{\max}]\) |
| \(p\) | 速度绝对值的幂指数，不是平均功率 | \([0,1]\) |
| \(c_{\max}\) | 题面给出的阻尼参数上界 | 100000 |

浮子和振子相对静平衡的垂荡位移记为 \(z_f(t)\)、\(z_o(t)\)，向上为正。速度和相对速度定义为

\[
v_f(t)=\frac{\mathrm d z_f}{\mathrm d t},\qquad
v_o(t)=\frac{\mathrm d z_o}{\mathrm d t},\qquad
v_r(t)=v_o(t)-v_f(t).
\]

\(v_f\) 是浮子速度，\(v_o\) 是振子速度，\(v_r\) 是振子相对浮子的速度，也就是阻尼器两端的相对速度。\(t\) 是时间。

## 模型成立条件

1. 浮子与振子只做小幅垂荡，附件 3 给出的附加质量和兴波阻尼在计算过程中保持不变。
2. 忽略中轴、底座、隔层、PTO 的质量以及题面要求忽略的机械摩擦。
3. PTO 输出功率取阻尼器吸收的机械功率；平均功率取初始瞬态消失后的稳定运动阶段。
4. 参与比较的阻尼参数均能使运动保持有界，并形成稳定的周期响应。

## 垂荡运动与功率模型

阻尼器沿相对运动方向的力记为 \(D(v_r)\)。两种阻尼规律为

\[
D(v_r)=
\begin{cases}
c\,v_r, & \text{常量阻尼},\\
c_0|v_r|^p v_r, & \text{速度相关阻尼}.
\end{cases}
\]

\(D\) 是阻尼力。第一种：力和相对速度成正比，\(c\) 是比例系数。第二种：\(c_0\) 是比例系数，\(p\) 是加在 \(|v_r|\) 上的指数，后面再乘 \(v_r\) 以保留力的方向。\(p=0\) 时第二种退化为第一种，且 \(c_0\) 相当于 \(c\)。

静平衡附近，浮子和振子的垂荡方程为

\[
\begin{cases}
(m_f+m_a)\dfrac{\mathrm d^2z_f}{\mathrm dt^2}
+b_h\dfrac{\mathrm d z_f}{\mathrm dt}
+K_hz_f-k(z_o-z_f)-D(v_r)=F\cos(\omega t),\\[8pt]
m_o\dfrac{\mathrm d^2z_o}{\mathrm dt^2}
+k(z_o-z_f)+D(v_r)=0.
\end{cases}
\tag{Q2-1}
\]

第一式是浮子：\(m_f+m_a\) 是浮子质量加附加质量，乘的是浮子加速度；\(b_h\dfrac{\mathrm d z_f}{\mathrm dt}\) 是兴波阻尼；\(K_hz_f\) 是静水恢复；\(-k(z_o-z_f)\) 把弹簧对浮子的力移到了左边；\(-D(v_r)\) 把阻尼器对浮子的力移到了左边；右边 \(F\cos(\omega t)\) 是波浪力。第二式是振子：振子不受直接波浪力，只受弹簧和阻尼，全部移到左边。\(z_o-z_f\) 是相对位移。

阻尼器在时刻 \(t\) 的瞬时机械功率等于阻尼力乘相对速度：

\[
P(t)=D(v_r)v_r=
\begin{cases}
c\,v_r^2, & \text{常量阻尼},\\
c_0|v_r|^{p+2}, & \text{速度相关阻尼}.
\end{cases}
\tag{Q2-2}
\]

\(P(t)\) 是瞬时输出功率。第一种把 \(D=cv_r\) 再乘 \(v_r\)，得到 \(c v_r^2\)。第二种再乘一次 \(v_r\)，指数从 \(p\) 变成 \(p+2\)。\(c\ge 0\)、\(c_0\ge 0\) 时 \(P(t)\ge 0\)，表示阻尼器只抽能、不供能。

波浪周期为 \(T=2\pi/\omega\)。给定一组阻尼参数 \(u\) 后，稳定阶段的平均输出功率定义为

\[
\overline P(u)=
\lim_{N\to\infty}\frac{1}{NT}
\int_{t_s}^{t_s+NT}P(t;u)\,\mathrm dt.
\tag{Q2-3}
\]

\(\overline P\) 是平均功率，上面一横表示对时间平均，不要和小写指数 \(p\) 混淆。\(u\) 是决策变量：常量阻尼时 \(u=c\)，速度相关阻尼时 \(u=(c_0,p)\)。\(P(t;u)\) 表示这组参数下的瞬时功率。\(t_s\) 是已经进入稳定运动的起始时刻。\(N\) 是用来平均的周期个数，取极限表示平均足够多个周期。\(T=2\pi/\omega\) 是一个波浪周期。

若稳定响应本身以 \(T\) 为周期，则只需积一个完整稳态周期：

\[
\overline P(u)=\frac{1}{T}\int_{t_s}^{t_s+T}P(t;u)\,\mathrm dt.
\]

\(1/T\) 把积分变成“一个周期内的平均值”。积分上下限从 \(t_s\) 到 \(t_s+T\)，正好一个周期。

## 常量阻尼的平均功率函数

### 稳态位移的余弦–正弦展开

常量阻尼时，式（Q2-1）是线性常系数方程。波浪力是 \(F\cos(\omega t)\)，稳定后浮子和振子也按同一个 \(\omega\) 往复。把位移写成与波浪同频率的余弦加正弦：

\[
\begin{aligned}
z_f(t)&=A_f\cos(\omega t)+B_f\sin(\omega t),\\
z_o(t)&=A_o\cos(\omega t)+B_o\sin(\omega t).
\end{aligned}
\]

\(A_f\) 是浮子位移中与波浪力同相位的那一部分（跟着 \(\cos(\omega t)\)），\(B_f\) 是落后或超前 \(90^\circ\) 的那一部分（跟着 \(\sin(\omega t)\)）。\(A_o,B_o\) 对振子含义相同。这四个数对给定的 \(c\) 是常数，不随时间变；时间只出现在 \(\cos(\omega t)\) 和 \(\sin(\omega t)\) 里。相对位移因此也是同频率的余弦加正弦：

\[
z_o(t)-z_f(t)=U\cos(\omega t)+W\sin(\omega t),
\]

其中

\[
U=A_o-A_f,\qquad W=B_o-B_f.
\]

\(U\) 是相对位移的余弦系数，\(W\) 是相对位移的正弦系数。相对位移振幅为

\[
X_{\mathrm{amp}}(c)=\sqrt{U^2+W^2}.
\]

\(X_{\mathrm{amp}}\) 是相对位移来回摆动的幅度。对时间求导后，相对速度为

\[
v_r(t)=-\omega U\sin(\omega t)+\omega W\cos(\omega t).
\]

\(-\omega U\sin(\omega t)\) 来自对 \(U\cos(\omega t)\) 求导，\(\omega W\cos(\omega t)\) 来自对 \(W\sin(\omega t)\) 求导。相对速度振幅为

\[
V(c)=\omega X_{\mathrm{amp}}(c)=\omega\sqrt{U^2+W^2}.
\]

\(V\) 是相对速度的振幅：简谐运动里，速度振幅等于圆频率乘位移振幅。

### 把装置参数先收成几个常数

后面公式会反复出现同一组质量、刚度与 \(\omega\) 的组合。先把它们算成与 \(c\) 无关的常数：

\[
q=\omega^2 m_o,\qquad
r_1=K_h-\omega^2(m_f+m_a),\qquad
r_2=\omega b_h.
\]

\(q\) 是振子惯性项 \(\omega^2 m_o\)。\(r_1\) 是浮子静水恢复减去浮子（含附加质量）的惯性。\(r_2\) 是兴波阻尼改写后与位移同类的一项。再令

\[
\begin{aligned}
a_1&=(k-q)r_1-kq,\\
a_2&=(k-q)r_2,\\
b_1&=r_1-q,\\
b_2&=r_2.
\end{aligned}
\]

\(a_1,a_2,b_1,b_2\) 仍不含决策变量 \(c\)，只由装置参数和波浪频率决定。\(a_1,a_2\) 出现在相对运动方程里与 \(c\) 无关的部分；\(b_1,b_2\) 出现在乘了 \(\omega c\) 的部分。这里的 \(b_1,b_2\) 不是兴波阻尼 \(b_h\)，只是两个辅助记号。

把上面的稳态表达式代入式（Q2-1），分别比较 \(\cos(\omega t)\) 和 \(\sin(\omega t)\) 的系数，并消去 \(A_f,B_f,A_o,B_o\)，得到关于 \(U,W\) 的二元一次方程组。解为

\[
\begin{aligned}
U(c)&=\frac{Fq\,(a_1-\omega c b_2)}{(a_1-\omega c b_2)^2+(a_2+\omega c b_1)^2},\\[6pt]
W(c)&=\frac{Fq\,(a_2+\omega c b_1)}{(a_1-\omega c b_2)^2+(a_2+\omega c b_1)^2}.
\end{aligned}
\tag{Q2-4}
\]

\(U(c),W(c)\) 是相对位移的两个待定系数，都随 \(c\) 变。分子里的 \(F\) 是波浪力振幅，\(q\) 是振子惯性项。分母是同一组实部、虚部式子的平方和：\(a_1-\omega c b_2\) 是与 \(\cos\) 对应的那一档，\(a_2+\omega c b_1\) 是与 \(\sin\) 对应的那一档。\(\omega c\) 表示阻尼系数经过圆频率后进入这组代数方程。于是

\[
X_{\mathrm{amp}}^2(c)=U(c)^2+W(c)^2
=\frac{F^2 q^2}{(a_1-\omega c b_2)^2+(a_2+\omega c b_1)^2}.
\]

相对位移振幅的平方等于分子 \(F^2 q^2\) 除以分母那两项平方和。\(c\) 变大时分母通常变大，相对运动变小。

### 由积分得到平均功率

常量阻尼下，稳态相对速度可以写成振幅为 \(V(c)\) 的单一正弦：

\[
v_r(t)=V(c)\sin(\omega t+\delta).
\]

\(V(c)\) 仍是相对速度振幅，\(\delta\) 是相对速度相对波浪力的相位差。把它代入 \(P=c v_r^2\) 再按一个周期平均：

\[
\begin{aligned}
\overline P(c)
&=\frac{1}{T}\int_{t_s}^{t_s+T}
c\,V^2(c)\sin^2(\omega t+\delta)\,\mathrm dt\\
&=c\,V^2(c)\cdot\frac12
=\frac12 c\,\omega^2 X_{\mathrm{amp}}^2(c).
\end{aligned}
\]

第一个等号就是平均功率的定义。\(\sin^2\) 在一个周期上的平均等于 \(1/2\)，所以出现 \(1/2\)。再把 \(V=\omega X_{\mathrm{amp}}\) 代进去，得到 \(\frac12 c\omega^2 X_{\mathrm{amp}}^2\)。将 \(X_{\mathrm{amp}}^2\) 的表达式代入，得到只含决策变量 \(c\) 的平均功率：

\[
\overline P(c)=
\frac{F^2\omega^2 q^2}{2}
\frac{c}
{(a_1-\omega c b_2)^2+(a_2+\omega c b_1)^2}.
\tag{Q2-5}
\]

\(\overline P(c)\) 是常量阻尼下的平均功率函数。分子里 \(F^2\omega^2 q^2/2\) 由波浪力、频率和振子惯性决定，不含 \(c\)；后面再乘 \(c\) 并除以分母。分母两项平方来自 \(U,W\) 的分母，已经没有单独的正弦、余弦。

为便于对 \(c\) 求导，把分母按 \(c\) 展开。记

\[
\begin{aligned}
A&=a_1^2+a_2^2,\\
B&=2\omega(a_2 b_1-a_1 b_2),\\
C&=\omega^2(b_1^2+b_2^2).
\end{aligned}
\tag{Q2-6}
\]

这里的 \(A,B,C\) 是分母多项式的三个系数，不是振幅 \(A_f\)，也不是阻尼 \(c\)。\(A\) 是常数项，\(B\) 是 \(c\) 的一次项系数，\(C\) 是 \(c^2\) 的二次项系数。于是

\[
\overline P(c)=
\frac{F^2\omega^2 q^2}{2}
\frac{c}{A+Bc+C c^2}.
\tag{Q2-7}
\]

分子对 \(c\) 是一次的，分母对 \(c\) 是二次的。对本题参数，\(A>0\)、\(C>0\)，且 \(A+Bc+Cc^2\) 等于式（Q2-5）中两个平方项之和，在可行域内始终为正，平均功率不会出现除以零。

## 常量阻尼最大功率的求解

常量阻尼的优化问题为

\[
\begin{aligned}
\max_c\quad &\overline P(c)\\
\mathrm{s.t.}\quad &0\le c\le c_{\max}.
\end{aligned}
\tag{Q2-8}
\]

\(\max_c\) 表示在允许的 \(c\) 里找让 \(\overline P(c)\) 最大的那个。约束是 \(c\) 落在 \([0,c_{\max}]\)。

对式（Q2-7）关于 \(c\) 求导。令 \(S=A+Bc+Cc^2\)，则 \(\overline P\) 正比于 \(c/S\)。导数为

\[
\begin{aligned}
\frac{\mathrm d\overline P}{\mathrm dc}
&=\frac{F^2\omega^2 q^2}{2}
\frac{S-c(B+2Cc)}{S^2}\\
&=\frac{F^2\omega^2 q^2}{2}
\frac{A-C c^2}{S^2}.
\end{aligned}
\]

\(\dfrac{\mathrm d\overline P}{\mathrm dc}\) 是平均功率随 \(c\) 的变化率。\(S-c(B+2Cc)\) 化简后只剩 \(A-Cc^2\)。分母 \(S^2\) 恒正，所以导数的正负只由 \(A-Cc^2\) 决定。

令导数等于零，得到唯一的正驻点

\[
c_s=\sqrt{\frac{A}{C}}.
\]

\(c_s\) 是使导数为零的阻尼值。当 \(0<c<c_s\) 时 \(A-Cc^2>0\)，平均功率随 \(c\) 增大；当 \(c>c_s\) 时 \(A-Cc^2<0\)，平均功率随 \(c\) 减小。因此 \(c_s\) 是无约束时的唯一全局最大点。

考虑题面的上界后，最优常量阻尼和相应最大平均功率为

\[
\begin{aligned}
c_1^*&=\min\left\{\sqrt{\frac{A}{C}},\ c_{\max}\right\},\\[4pt]
P_1^*&=
\begin{cases}
\dfrac{F^2\omega^2 q^2}{2\left(B+2\sqrt{AC}\right)},
& c_s\le c_{\max},\\[10pt]
\dfrac{F^2\omega^2 q^2}{2}
\dfrac{c_{\max}}{A+B c_{\max}+C c_{\max}^2},
& c_s>c_{\max}.
\end{cases}
\end{aligned}
\tag{Q2-9}
\]

\(c_1^*\) 是最终采用的常量阻尼，\(P_1^*\) 是对应的最大平均功率。\(\min\{\sqrt{A/C},\,c_{\max}\}\) 表示：驻点没超过上界就取驻点，超过了就取上界 \(c_{\max}\)。第一行 \(P_1^*\) 是把 \(c=c_s\) 代回式（Q2-7）后的化简结果；第二行是把 \(c=c_{\max}\) 直接代入式（Q2-7）。

## 速度相关阻尼的优化模型

速度相关阻尼满足 \(D(v_r)=c_0|v_r|^p v_r\)。阻尼力随相对速度改变，式（Q2-1）成为非线性方程组，稳定相对速度一般含有高次谐波，不能再写成单一正弦。因此本情形的正式平均功率始终由式（Q2-3）的时间积分计算。

优化问题为

\[
\begin{aligned}
\max_{c_0,p}\quad &\overline P(c_0,p)\\
\mathrm{s.t.}\quad
&0\le c_0\le c_{\max},\\
&0\le p\le 1,\\
&z_f(t),z_o(t)\text{ 满足式（Q2-1）及给定初始条件},\\
&z_f(t),z_o(t),v_f(t),v_o(t)\text{ 长期有界}.
\end{aligned}
\tag{Q2-10}
\]

\(\max_{c_0,p}\) 表示同时选择比例系数和幂指数，使平均功率最大。\(c_0\) 的范围与第一种的 \(c\) 相同，\(p\) 只能在 \(0\) 到 \(1\) 之间。后两条约束要求位移、速度由运动方程积出来，并且不能发散。

### 给定一组参数时平均功率的计算

为使用四阶 Runge–Kutta 方法求解式（Q2-1），把两个二阶方程写成四个一阶方程。给定 \((c_0,p)\) 后，

\[
\begin{cases}
\dfrac{\mathrm d z_f}{\mathrm dt}=v_f,\\[6pt]
\dfrac{\mathrm d v_f}{\mathrm dt}=
\dfrac{F\cos(\omega t)-b_h v_f-K_h z_f+k(z_o-z_f)+c_0|v_r|^p v_r}
{m_f+m_a},\\[12pt]
\dfrac{\mathrm d z_o}{\mathrm dt}=v_o,\\[6pt]
\dfrac{\mathrm d v_o}{\mathrm dt}=
-\dfrac{k(z_o-z_f)+c_0|v_r|^p v_r}{m_o},\\[8pt]
v_r=v_o-v_f.
\end{cases}
\]

第一行：浮子位移的变化率就是浮子速度。第二行：浮子加速度，由式（Q2-1）第一式解出，分母是浮子等效质量。第三行：振子位移的变化率就是振子速度。第四行：振子加速度，由式（Q2-1）第二式解出。\(c_0|v_r|^p v_r\) 就是这时的阻尼力 \(D\)。

初始时刻装置位于静平衡、速度为零：

\[
z_f(0)=z_o(0)=v_f(0)=v_o(0)=0.
\]

四个量从零开始，对应题目“初始静水平衡”。

数值积分持续到相邻完整周期的四个状态之差小于状态容差 \(\delta_x\)，且相邻周期平均功率之差小于功率容差 \(\delta_P\)。达到稳定后，在连续 \(N\) 个完整周期上计算平均功率。

设积分步长为 \(h\)，平均区间内的步数为 \(M=NT/h\)，取样时刻为 \(t_j=t_s+jh\)。梯形积分给出的平均功率为

\[
\overline P_h(c_0,p)=
\frac{h}{NT}
\left[
\frac{P(t_0)}{2}
+\sum_{j=1}^{M-1}P(t_j)
+\frac{P(t_M)}{2}
\right],
\]

\(\overline P_h\) 是用步长 \(h\) 算出来的平均功率近似值。\(\dfrac{h}{NT}\) 把各点上的 \(P\) 加起来后除以总时长 \(NT\)。首尾两点 \(P(t_0),P(t_M)\) 各算一半，中间点全算，这就是梯形法。其中

\[
P(t_j)=c_0\bigl|v_r(t_j)\bigr|^{p+2}.
\]

\(t_j\) 是第 \(j\) 个取样时刻，\(v_r(t_j)\) 是该时刻由 RK4 得到的相对速度。这一步完成从一组 \((c_0,p)\) 到一个平均功率值的计算。

### 最大平均功率的搜索

速度相关阻尼的最大值按以下顺序求得：

1. 在 \([0,c_{\max}]\times[0,1]\) 内设置均匀网格，对每个 \((c_0,p)\) 依次求解运动方程并计算 \(\overline P_h(c_0,p)\)。
2. 取当前网格中平均功率最大的参数点，并逐次缩小 \(c_0\) 与 \(p\) 的网格间距；每次加密后都重新比较整个可行域及四条边界上的功率。
3. 当相邻两次加密得到的最大功率之差小于 \(\delta_P\)，且两个最优参数的变化分别小于给定参数容差时，停止加密。
4. 将时间步长减半并增加平均周期数，重新计算最优点及其邻域；若最大功率和最优参数在容差内保持不变，则接受该数值解。

可行域是闭且有界的矩形。在稳定解随参数连续变化的条件下，平均功率也是连续函数。随着全域网格间距趋于零，网格上的最大值趋近于式（Q2-10）的全局最大值。该方法同时检查内部峰值和边界峰值。

### 单频近似的辅助核对

若稳定相对速度的基频分量占主导，可近似写成 \(v_r(t)\approx V\sin(\omega t+\delta)\)。定义一个周期内 \(\lvert\sin s\rvert^{p+2}\) 的平均值为

\[
L(p)=\frac{1}{2\pi}\int_0^{2\pi}\lvert\sin s\rvert^{p+2}\,\mathrm ds.
\]

\(L(p)\) 只依赖指数 \(p\)，是把 \(\lvert\sin\rvert^{p+2}\) 在 \(0\) 到 \(2\pi\) 上平均后的纯数字。\(s\) 是积分用的无量纲角度。近似平均功率为 \(c_0 L(p) V^{p+2}\)。令一个常量阻尼器在相同速度振幅下具有相同平均功率，得到等效阻尼系数

\[
c_{\mathrm{eq}}=2c_0 L(p) V^p,
\qquad
V=\omega X_{\mathrm{amp}}(c_{\mathrm{eq}}).
\]

\(c_{\mathrm{eq}}\) 是“如果改用常量阻尼、要产生同样平均功率，大约该取多大的 \(c\)”。\(V=\omega X_{\mathrm{amp}}(c_{\mathrm{eq}})\) 表示这个等效 \(c\) 仍用本节的 \(U,W\) 公式计算相对速度振幅。这两个关系只用于检查量级和提供搜索初值。速度相关阻尼的最终最大功率仍以 RK4 时域响应和式（Q2-3）的数值积分为准。

## 约束、边界与模型输出

两种阻尼情形的决策域分别为 \([0,c_{\max}]\) 和 \([0,c_{\max}]\times[0,1]\)。任何未达到稳定状态、运动无界或平均功率不能收敛的参数点均不参与有效功率比较。

常量阻尼情形输出最优阻尼系数和最大平均功率

\[
(c_1^*,P_1^*)=
\left(
\operatorname*{arg\,max}_{0\le c\le c_{\max}}\overline P(c),
\max_{0\le c\le c_{\max}}\overline P(c)
\right).
\]

\(\operatorname{arg\,max}\) 是使 \(\overline P(c)\) 取到最大的那个 \(c\)，右边 \(\max\) 是这个最大值本身。\(c_1^*\) 和 \(P_1^*\) 由式（Q2-9）直接计算，并用时域积分核对。

速度相关阻尼情形输出最优比例系数、最优幂指数和最大平均功率：

\[
\begin{aligned}
(c_0^*,p^*)&=
\operatorname*{arg\,max}_{(c_0,p)\in[0,c_{\max}]\times[0,1]}
\overline P(c_0,p),\\
P_2^*&=\overline P(c_0^*,p^*).
\end{aligned}
\tag{Q2-11}
\]

\(c_0^*\) 是最优比例系数，\(p^*\) 是最优幂指数，\(P_2^*\) 是第二种情形的最大平均功率。相应的最优阻尼力为

\[
D^*(v_r)=c_0^*\lvert v_r\rvert^{p^*} v_r.
\]

\(D^*\) 是最优点上的阻尼力公式，把最优的 \(c_0^*,p^*\) 代回第二种阻尼规律。

除最优值外，求解阶段还应保留最优点邻域、四条边界、时间步长减半和平均周期数增加后的功率，以支持最大值与数值收敛性的判断。
